# 🛡️ Viva sua Profissão | Guia de Carreira: Engenheiro DevSecOps

Projeto web desenvolvido para orientar estudantes e profissionais de tecnologia sobre a carreira de **Engenharia DevSecOps**, reunindo o conceito da área, habilidades técnicas e interpessoais exigidas pelo mercado, certificações reconhecidas e laboratórios práticos.

---

## 🎯 Sobre o Projeto

Enquanto o DevOps foca em agilidade no desenvolvimento e operações, o **DevSecOps** integra a segurança em todas as etapas do ciclo de vida do software. Este portal apresenta um guia direto e estruturado para quem deseja ingressar ou evoluir nessa área.

### Páginas incluídas:
* **Início (`index.html`):** Introdução ao papel do Engenheiro DevSecOps e suas principais responsabilidades (SAST, SCA, DAST, segurança em nuvem).
* **Habilidades (`pages/habilidades.html`):** Detalhamento das competências técnicas (Python, Go, Terraform, Docker, Kubernetes, Snyk, OWASP ZAP) e *soft skills*.
* **Materiais (`pages/materiais.html`):** Trilha de certificações (CISM, CKS, AWS Security) e ambientes de prática (OWASP Juice Shop, DVWA, TryHackMe, Hack The Box).
* **Sobre (`pages/sobre.html`):** Propósito da iniciativa *Viva sua Profissão*.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* **CSS3:** Estilização customizada com Flexbox, variáveis de layout responsivo e tema escuro voltado para cibersegurança.

## 🚀 Como executar localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd nome-do-repositorio
   ```
3. Abra o arquivo `index.html` diretamente no seu navegador ou utilize a extensão **Live Server** no VS Code.
